# Система коллекционирования комиксов

Консольное объектно-ориентированное приложение для ведения личных коллекций комиксов.

## Возможности

- создание пользователей и личных коллекций;
- ведение каталога серий и выпусков;
- добавление и удаление выпусков из коллекции;
- отметка прочитанных выпусков и выставление оценок;
- поиск, фильтрация и сортировка данных;
- просмотр недостающих выпусков и статистики;
- сохранение связанных объектов в JSON.

## Объектная модель

- `User` — пользователь и владелец коллекции;
- `Series` — серия комиксов с автором и количеством выпусков;
- `Issue` — выпуск, связанный с объектом серии;
- `Collection` — коллекция, связанная с пользователем и выпусками.

Классы содержат конструкторы, строковые представления, свойства, обычные, статические и классовые методы. Связи между объектами восстанавливаются при загрузке данных.

## Структура проекта

- `main.py` — меню и пользовательские сценарии;
- `models/` — классы предметной области и операции над ними;
- `storage.py` — сериализация объектов в JSON;
- `utils.py` — безопасный ввод;
- `data/` — данные приложения;
- `tests/` — автоматизированные тесты.

## Установка и запуск

```bash
python -m venv .venv
pip install -r requirements.txt
python main.py
```
