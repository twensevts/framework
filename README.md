# Система коллекционирования комиксов

## Назначение

Консольное приложение для учёта, систематизации и отслеживания личной коллекции комиксов.

## Целевая аудитория

Коллекционеры физических изданий и любители комиксов, которым нужен инструмент для управления домашней библиотекой.

## Предметная область

Приложение хранит сведения о пользователях, сериях, отдельных выпусках и личных коллекциях, помогает отслеживать прогресс, прочитанные выпуски и пользовательские оценки.

## Основные сущности

- пользователь;
- серия комиксов;
- выпуск комикса;
- коллекция.

## Основные функции

- определение статуса чтения выпуска;
- расчёт количества недостающих выпусков серии;
- проверка и отображение пользовательской оценки.

## Запуск

```bash
python main.py
```

## План развития

На следующих этапах планируется:

- обработка коллекций выпусков;
- поиск, фильтрация, сортировка и статистика;
- хранение данных в JSON-файлах;
- разделение программы на модули;
- разработка объектной модели;
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
