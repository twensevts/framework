# Система коллекционирования комиксов

## Назначение
Приложение предназначено для учета, систематизации и отслеживания собранных томов комиксов.

## Целевая аудитория
Коллекционеры физических изданий и любители комиксов, которым требуется инструмент для управления домашней библиотекой.

## Предметная область
Библиотека комиксов. Учет любимых комиксов, авторов и конкретных томов.

## Основные сущности
- Автор
- Серия комиксов
- Номер выпуска
- Издательство

## Возможности
- просмотр всех добавленных серий;
- добавление новых серий комиксов;
- добавление конкретных выпусков в серию;
- возможность выбрать статус комикса (прочитан / нет);
- автоматическое сохранение данных при выходе из программы.

## Структура проекта
- `main.py` — точка запуска;
- `series.py` — работа с сериями комиксов;
- `comics.py` — работа с конкретными выпусками;
- `storage.py` — сохранение и загрузка данных;
- `utils.py` — вспомогательные функции (безопасный ввод);
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Требования
- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:
`pip install -r requirements.txt`

## Запуск программы
`python main.py`

## Запуск тестов
`pytest`

## Проверка качества кода
`flake8`
