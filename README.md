# Система коллекционирования комиксов

## Назначение

«Система коллекционирования комиксов» — консольное приложение для управления личными коллекциями комиксов.

Приложение позволяет:

* просматривать серии комиксов;
* находить серии по названию или автору;
* добавлять новые серии;
* создавать пользователей;
* создавать личные коллекции;
* добавлять выпуски в коллекцию;
* удалять выпуски из коллекции;
* отмечать выпуски прочитанными;
* выставлять выпускам оценки;
* просматривать недостающие выпуски;
* просматривать статистику коллекции;
* хранить данные между запусками приложения.

## Целевая аудитория

Пользователи, которым необходимо вести личную коллекцию комиксов, учитывать имеющиеся выпуски и отслеживать прочитанные номера.

## Предметная область

Основными объектами предметной области являются:

* пользователь;
* серия комиксов;
* выпуск комикса;
* коллекция.

Пользователь может создавать личную коллекцию и добавлять в неё выпуски комиксов.

Один выпуск относится к одной серии комиксов и не может быть дважды добавлен в одну коллекцию.

Для выпуска можно указать статус прочтения и оценку от 1 до 5.

## Основные сущности

### `User` — пользователь

Объект `User` представляет пользователя системы.

Основные атрибуты:

* `id` — уникальный идентификатор пользователя;
* `name` — имя пользователя;
* `email` — адрес электронной почты.

Основные методы:

* `validate_email()` — проверка адреса электронной почты;
* `__str__()` — строковое представление пользователя;
* `from_data()` — создание объекта `User` из набора данных.

### `Series` — серия комиксов

Объект `Series` представляет серию комиксов.

Основные атрибуты:

* `id` — уникальный идентификатор серии;
* `title` — название серии;
* `author` — автор серии;
* `total_issues` — количество выпусков.

Основные методы:

* `has_issue()` — проверка существования номера выпуска в серии;
* `__str__()` — строковое представление серии;
* `from_data()` — создание объекта `Series` из набора данных.

### `Issue` — выпуск комикса

Объект `Issue` представляет отдельный выпуск серии комиксов.

Основные атрибуты:

* `id` — уникальный идентификатор выпуска;
* `series` — объект `Series`;
* `number` — номер выпуска;
* `is_read` — признак прочтения;
* `rating` — оценка выпуска.

Основные методы:

* `mark_as_read()` — отметка выпуска прочитанным;
* `rate()` — выставление оценки выпуску;
* `__str__()` — строковое представление выпуска.

### `Collection` — коллекция

Объект `Collection` представляет коллекцию выпусков пользователя.

Основные атрибуты:

* `id` — уникальный идентификатор коллекции;
* `user` — объект `User`;
* `issues` — список объектов `Issue`.

Основные методы:

* `add_issue()` — добавление выпуска в коллекцию;
* `remove_issue()` — удаление выпуска из коллекции;
* `get_series_issues()` — получение выпусков выбранной серии;
* `missing_issue_numbers()` — определение недостающих выпусков;
* `statistics()` — получение статистики коллекции;
* `__str__()` — строковое представление коллекции.

## Основные операции

### Работа с сериями

* добавление серии;
* поиск серии по названию или автору;
* проверка существования номера выпуска;
* сортировка серий;
* просмотр списка серий.

### Работа с пользователями

* создание пользователя;
* поиск пользователя;
* просмотр информации о пользователе.

### Работа с выпусками и коллекциями

* создание выпуска;
* добавление выпуска в коллекцию;
* удаление выпуска из коллекции;
* изменение статуса прочтения;
* выставление оценки;
* просмотр списка выпусков;
* поиск недостающих выпусков;
* просмотр статистики коллекции.

При добавлении выпуска проверяется наличие этого выпуска в коллекции.

## Хранение данных

Данные приложения хранятся в JSON-файлах:

* `data/users.json`;
* `data/series.json`;
* `data/issues.json`;
* `data/collections.json`.

При загрузке данные из JSON преобразуются в объекты `User`, `Series`, `Issue` и `Collection`.

При сохранении объекты преобразуются в данные JSON.

Для связи выпуска с серией в `issues.json` используется идентификатор `series_id`. Для связи коллекции с пользователем и выпусками в `collections.json` используются идентификатор `user_id` и список `issue_ids`.

## Назначение модулей

### `main.py`

Точка входа в приложение.

Отвечает за:

* запуск приложения;
* отображение меню;
* получение данных от пользователя;
* организацию пользовательских сценариев.

### `models/users.py`

Содержит класс `User` и функции работы с пользователями.

### `models/series.py`

Содержит класс `Series` и функции работы с сериями комиксов.

### `models/issues.py`

Содержит класс `Issue` и функции работы с выпусками комиксов.

### `models/collections.py`

Содержит класс `Collection` и функции работы с коллекциями.

### `storage.py`

Отвечает за загрузку и сохранение данных.

Выполняет преобразования:

* JSON → объекты Python;
* объекты Python → JSON.

### `utils.py`

Содержит вспомогательные функции:

* `input_int()` — безопасный ввод целого числа;
* `input_rating()` — безопасный ввод оценки.

### `tests/`

Содержит автоматизированные тесты проекта.

## Запуск приложения

Для запуска приложения выполнить:

```text
python main.py
```

* связь коллекции с пользователем и выпусками;
