# Система коллекционирования комиксов

Консольное приложение для ведения личных коллекций комиксов.

## Возможности

- создание пользователей и их коллекций;
- добавление и поиск серий;
- добавление выпусков в коллекцию;
- отметка прочитанных выпусков и выставление оценок;
- поиск, фильтрация и сортировка данных;
- просмотр недостающих выпусков и статистики;
- сохранение данных между запусками.

## Сущности

- **Пользователь** — владелец коллекции;
- **Серия** — серия комиксов с автором и количеством выпусков;
- **Выпуск** — конкретный номер серии со статусом чтения и оценкой;
- **Коллекция** — набор выпусков определённого пользователя.

## Структура проекта

- `main.py` — меню и пользовательские сценарии;
- `users.py` — работа с пользователями;
- `series.py` — работа с сериями;
- `issues.py` — работа с выпусками;
- `collection.py` — работа с коллекциями и статистикой;
- `storage.py` — загрузка и сохранение JSON;
- `utils.py` — безопасный ввод;
- `data/` — данные приложения;
- `tests/` — автоматизированные тесты.

## Установка и запуск

```bash
python -m venv .venv
pip install -r requirements.txt
python main.py
```
