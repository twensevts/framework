# Система коллекционирования комиксов

## Назначение
Приложение предназначено для учета, систематизации и отслеживания собранных томов комиксов.

## Целевая аудитория
Коллекционеры физических изданий и любители комиксов, которым требуется инструмент для управления домашней библиотекой.

## Предметная область
Библиотека комиксов. Учет любимых комиксов, авторов и конкретных томов.

## Основные сущности
- Автор
- Серия комиксов
- Номер выпуска
- Издательство

## Основные функции
- Возможность выбрать статус комикса (прочитан/нет).
- Отображение всех и еще не приобретенных выпусков серии.
- Оценка выпуска комикса.

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
